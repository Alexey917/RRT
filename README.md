# RRT

RRT(React + Redux + Typescript) - решение задач для практического изучения redux, работы с API, создания кастомных селектов, знакомоство с библиотекой react-select

## Ключевые особенности и решения

*   **работа с нативным redux:** создание reducer'ов, типизация action'ов, создание фанков для получение массива данных по API([jsonplaceholder](https://jsonplaceholder.typicode.com))? кастомные хуки для useSelector и фанков(useAction), получение данных из хранилища, состояние загруки и состояние ошибки
*   **список дел с пагинацией:** получение списка дел по апи и сохранение его в стейт с последующим отображением и разбивкой на страницы
*   **реализация бесконечного скролла:** подгрузка данных с помощью IntersectionObserver
*   **разработка кастомных селектов(с одним выбором, с множественным выбором):** написание собственных селектов с одиночным и множественных выбором, открытием и закрытием выпадающего списка, стилизацией выбранных пунктов
*   **фильтрация с сортировкой списка:** добавление фильтрации через поле input и кнопку поиска, добавление сортировки по выбранным опциям из селекта и сочетание с фильтрацией
*   **создание ранее реализованных селектов через библиотеку react-select:** ознакомление с библиотекой react-select посредством создания селектов, похожих визуально на кастомные и выполняющих тот же функционал

## Технологический стек

*   **React**
*   **Redux**
*   **Typescript** 
*   **React Select**
